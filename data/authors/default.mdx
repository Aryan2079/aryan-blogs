## Hi, I'm Aryan Bhattarai

I build LLM systems for places where a wrong answer has a cost. Most of my work is the part around the model: what it is allowed to call, what it is allowed to say, and how I know it works.

I have spent 4+ years building production LLM systems for fintech and banking: RAG assistants with hybrid search, reranking and LLM-as-judge evaluation, LoRA fine-tuning served on vLLM, and LangGraph agents with SQL tool-calling, authentication, tenant isolation, LLM security testing and GPU deployment.

Since July 2026 I have been an AI Engineer at InfoDevelopers, working on INFINITY AI, a multi-tenant AI middleware for co-operative core banking. I built the LangGraph agent pipeline, designed the SQL Server tools and stored procedures so the database does the maths and the model only explains the results, built a star-schema warehouse for daily metrics and ratios, implemented the authentication and tenant isolation, integrated LLM Guard on load-balanced GPU replicas, moved the system to a GPU server, and wrote about 400 automated tests plus a black-box API test that found a login lockout bypass.

Before that I spent nearly four years at Microcode Technologies, a fintech software company building loan management and core banking systems. I started as a frontend intern on the Loan Management System in React and TypeScript, then worked as a Junior AI Engineer: I built a RAG assistant for lending policy and law questions (tuned to 92% accuracy on a 500-question LLM-as-judge evaluation), fine-tuned Qwen-7B-Chat with LoRA and served it on vLLM, built Hautu, an in-app "how do I..." assistant, added PII redaction and prompt-injection testing, and built a facial-recognition attendance system.

In early 2026 I was a data engineering intern at GrowByData, building Airflow ETL pipelines with pandas and SQL and scraping search results and LLM answers for SEO and AI-visibility analytics. I finished my B.E. in Computer and Electronics Engineering at Kantipur Engineering College (Tribhuvan University, 2026). I co-authored a paper on glaucoma detection from retinal images, using an Attention U-Net and DeiT-Tiny, with 89.77% accuracy and an AUC of 0.956 on 12,449 images. It was published in the [International Journal on Engineering Technology](https://doi.org/10.3126/injet.v3i2.95539).
