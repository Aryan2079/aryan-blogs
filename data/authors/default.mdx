## Hi, I'm Aryan Bhattarai

I build LLM systems for places where a wrong answer has a cost. Most of my work is the part around the model: what it is allowed to call, what it is allowed to say, and how I know it works.

Since July 2026 I have been an AI Engineer Trainee at InfoDevelopers, working on INFINITY AI, a multi-tenant AI middleware for co-operative banking. I built the LangGraph agent pipeline, designed the SQL Server tools so the database does the maths and the model only explains the results, built the authentication and tenant isolation, integrated an LLM Guard service on GPU replicas, moved the system to a GPU server, and wrote about 400 automated tests.

Before that I was a data engineering intern at GrowByData, working on Airflow ETL pipelines with pandas and SQL. I finished my B.E. in Computer and Electronics Engineering at Kantipur Engineering College (Tribhuvan University, 2026). I co-authored a paper on glaucoma detection from retinal images, using an Attention U-Net and DeiT-Tiny, with 89.77% accuracy and an AUC of 0.956 on 12,449 images. It was published in the [International Journal on Engineering Technology](https://doi.org/10.3126/injet.v3i2.95539).
